# Changelog - apps.yug-avto.ru (Монолит / Go API)

## [2026-08-17]
### Added
- Внедрена валидация и санитизация фильтров (Sanitization) в Go API (`service.go`, `handler_vehicles.go`, `handler_filter.go`, `handler_brands.go`):
  - In-memory кэширование справочников (`brands`, `models`, `bodies`, `engines`, `drives`, `transmissions`, `colors`) со сверхбыстрой валидацией параметров.
  - Мягкая фильтрация при мультивыборе (отбрасывание неизвестных токенов при сохранении валидных).
  - Сигнал «Битый роут» (`code: 404, force_404: true`) при запросе параметров с неизвестными значениями, позволяющий клиентским сайтам мгновенно отдавать 404 без лишних тяжелых запросов.

## [2026-08-07]
### Added
- Добавлена возможность интерактивного поиска по `vehicle_id` в веб-интерфейсе отображения сырых данных AutoCRM (`_autocrm.php`).
- Реализовано автоматическое добавление суффикса страницы (` — Страница #N`) к `meta.title` на стороне Go API (`meta.go`, `buildCatalogMeta`) при запросах списка витрины с пагинацией (`page > 1`).

## [2026-08-04]
### Added
- Внедрена нормализация и агрегация скидок в Go API (`discounts.go`, `convert.go`, `handler_vehicles.go`):
  - Приведение сырых названий скидок из 1С / AutoCRM к стандартизированным категориям («Трейд-ин», «Кредит», «Трейд-ин + Кредит», «Прямая скидка», «Семейный автомобиль», «КАСКО в подарок» и др.).
  - Автоматическое объединение скидок одного типа для каждого авто и суммирование их значений (`sum`).

### Fixed
- Исправлена генерация URL/алиасов моделей в Go API (`generateModelAlias` в `service.go`):
  - Префиксы «Новый», «Новая», «Новое», «Новые», «New» теперь корректно выносятся в конец кода модели в формате суффикса `-new` (например, `granta-sedan-new` вместо `novaya-granta-sedan`).
  - Выполнена массовая перегенерация кодов существующих моделей в БД `yapps_app_cis_models_new` и `yapps_app_cis_models_used`.

## [2026-08-03]
### Fixed
- Оптимизирован алгоритм подмешивания CTA-карточек в Go API (`handler_vehicles.go`). Внедрен гарантированный минимальный отступ (`minGap = 12`) между баннерами и учет сквозной пагинации (`page`), устраняющий появление 2 баннеров в одном или соседних рядах при любых разрешениях экрана. Добавлена поддержка параметра `mode=used`/`mode=new` для витрины Эксперта.
- Исправлена обработка тегов из AutoCRM в Go API (`getTagsForVehicle` в `convert.go`). Теперь вместо 2 захардкоженных синтетических флагов Go API динамически сопоставляет теги из `raw.Tags` со справочной таблицей БД `yapps_app_cis_tags` и формирует полный список тегов автомобиля с их SVG-иконками.
- Проведена точечная принудительная переобработка и увеличение фотографий для 100% карточек б/у (719 авто) и новых автомобилей (2066 авто) в Go API. Разрешения полноразмерных фото всех авто на сервере приведены к `1268x1000`, а превью — к `460x354`.

## [2026-07-31]
### Changed
- Переключена сортировка и фильтрация по цене в Go API с базовой цены (v.price) на конечную цену со скидками (v.min_price) для соответствия отображению на фронтенде.
- Добавлен автоматический вывод оригинальных фотографий из AutoCRM (row.Raw), если локально обработанные WebP-картинки еще не скачались.
- В структуру `ImageResp` добавлено поле `preview_small` для полного соответствия шаблонам Bitrix.
- Увеличены размеры ресайза изображений в 2 раза для полноразмерных фото (`1268x1000`) и в 1.5 раза для превью (`460x354`).
