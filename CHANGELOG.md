# Changelog

## 07.07.2026
- **Исправление Fatal Error на PHP 8.x (TypeError при array_chunk(null) на пустых/отсутствующих картинках)**:
  - В методе `apiDBGetVehicles` класса `core/YApps/Cis.php` (для дев- и прод-версий) добавлена вспомогательная безопасная функция-обертка `safeGetImages`, которая проверяет массив изображений перед делением на чанки с помощью `array_chunk`. Это предотвращает критическую ошибку `TypeError: array_chunk(): Argument #1 ($array) must be of type array, null given`, из-за которой падали все API-запросы списков автомобилей (например, `/API/get/cis/vehicles/new?sort=datetime_down`), если хотя бы у одного автомобиля отсутствовали фотографии.
  - Также защищены все остальные вызовы `array_chunk` (включая нарезку характеристик `$res['specifications']` в детальной карточке автомобиля).
- **Исправление формата писем PHPMailer (переход на CRLF)**:
  - В классе `core/YApps/PHPMailer.php` (для дев- и прод-версий) изменено значение разделителя строк `$LE` (Line Ending) с `\n` на стандартный `\r\n`. После переезда на новый сервер локальный почтовый транспорт стал строго требовать переводы строк CRLF для заголовков писем. Ранее из-за `\n` заголовки MIME некорректно обрабатывались сервером и попадали в тело письма, из-за чего уведомления (включая лиды с виджетов) приходили в сыром текстовом виде с MIME-разделителями вместо HTML.
- **Предотвращение 502 Bad Gateway из-за системного логирования (SIGPIPE) и локальный php_error.log**:
  - В файле `index.php` (для дев- и прод-версий) добавлено явное переопределение пути логирования PHP-ошибок: `ini_set('error_log', __DIR__ . '/core/YApps/Logs/php_error.log');`. Ранее при возникновении большого количества предупреждений PHP-FPM воркеры пытались отправить их в системный поток ошибок (stderr), но из-за отключенного перехвата вывода в настройках пула Fastpanel (`catch_workers_output = no`) процесс FPM получал сигнал `SIGPIPE` (запись в закрытый канал) и аварийно завершался, выдавая 502 ошибку в Nginx. Перенаправление в локальный файл полностью решило эту проблему.
- **Исправление Fatal Error на PHP 8.x (TypeError при count($d) на карточке авто)**:
  - В методе `apiDBGetVehicle` класса `core/YApps/Cis.php` (для дев- и прод-версий) добавлена проверка `!empty($d) && is_array($d)` перед вызовом функции `count($d)` на строке 3090. Ранее обращение к неопределенной переменной `$d` в PHP 8.5.0 приводило к фатальной ошибке `TypeError` и падению процесса с выдачей 502 Bad Gateway при открытии детальной карточки автомобиля.
