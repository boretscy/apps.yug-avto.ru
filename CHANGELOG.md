# Changelog - apps.yug-avto.ru (Монолит / Go API)

## [2026-09-03]
### Fixed
- Исправлена фатальная ошибка PHP 8.x `TypeError: implode()` при открытии формы создания нового виджета обратного звонка (`/widgets_v3/cb/new/`) и генератора лидов (`/widgets_v3/lg/new/`):
  - Обеспечена безопасная инициализация массива параметров `$arRes = []` по умолчанию при отсутствии `$currentRoute->id`.
  - Добавлена строгая проверка `(!empty($arRes['recipients']) && is_array($arRes['recipients'])) ? implode(...) : ''` перед форматированием списка получателей формы в `_cb.php` и `_lg.php`.
  - Исправлены устаревшие обращения к модулю `$app->Widgets` вместо `$app->Widgets3` в заголовке формы `_cb.php` и в представлении `view_tuning.php`.

## [2026-08-28]
### Changed
- Обновлен вывод маркировки для виджета LG (`core/YApps/Widgets3.php`, `core/YApps/html/Widgets3/LG.html`):
  - Префикс «Реклама. » перенесен из HTML-шаблона в обработчик `Widgets3.php` при формировании тега `%% WIDGET_MARKING %%` с проверкой на непустое значение маркировки.

### Fixed
- Исправлено расхождение количества автомобилей между `/api/v1/cis/filter` и `/api/v1/cis/vehicles` при фильтрации по автосалону (`dealership`) и другим параметрам (`handler_filter.go`):
  - Добавлен парсинг параметра `dealership` (по slug/id) в структуру `VehicleFilter`.
  - Условия `where` и `whereNoPrice` теперь формируются через универсальный метод `buildConditions(filter)`, обеспечивая строгий учет автосалона, КПП, двигателя, привода, кузова, цвета, года выпуска и других параметров во всех агрегированных списках моделей (`dropLists.models`), брендов (`dropLists.brands`), диапазонов и `totalCount`.

## [2026-08-18]
### Fixed
- Перенесены правила обработки и нормализации бренда Nordcross в Go API (`service.go`):
  - При синхронизации брендов (`SyncBrands`) бренд `Nordcross` переименовывается в `Nordcross (Lynk & Co)` с алиасом `nordcross-(lynk-co)` и русским названием `Нордкросс`.
  - Добавлены статические исключения русских брендов в `generateBrandAlias` (ГАЗ, ЗАЗ, УАЗ, ТагАЗ, Москвич, Амберавто, LADA (ВАЗ)).
  - Нормализована существующая запись бренда `Nordcross (Lynk & Co)` в таблице `yapps_app_cis_brands`.
- Исправлено формирование списка моделей в фильтре при выборе нескольких брендов (`handler_filter.go`):
  - Параметры брендов (`brand`), моделей (`model`) и цен теперь считываются из структуры `VehicleFilter`, поддерживающей множественные значения (`brand[0]`, `brand[1]` и `brand=a,b`), вместо одиночного `q.Get()`.
  - Устранена ошибка, из-за которой выпадающий список моделей на витрине при выборе 2 и более брендов оставался пустым.

## [2026-08-17]
### Fixed
- Исправлена синхронизация и удаление проданных автомобилей в Go API (`sync.go`, `mysql.go`):
  - Добавлена строгая фильтрация при постраничном чтении новых и б/у автомобилей из AutoCRM: в обработку попадают только авто с активными статусами (`1: В наличии` и `2: В пути`), отсекая проданные (`3: Продан`).
  - Реализовано безопасное батчевое удаление проданных/снятых автомобилей из БД частями по 500 записей (`deleteSoldVehicles`), исключающее сбои при обработке больших объемов.
  - Оптимизирован пул соединений MySQL (`db.SetConnMaxLifetime`, `db.SetConnMaxIdleTime`), предотвращающий ошибку `invalid connection` при длительных операциях синхронизации.
  - Выполнена очистка зависших проданных автомобилей в активной таблице витрины.

### Added
- Внедрена валидация и санитизация фильтров (Sanitization) в Go API (`service.go`, `handler_vehicles.go`, `handler_filter.go`, `handler_brands.go`):
  - In-memory кэширование справочников (`brands`, `models`, `bodies`, `engines`, `drives`, `transmissions`, `colors`) со сверхбыстрой валидацией параметров.
  - Мягкая фильтрация при мультивыборе (отбрасывание неизвестных токенов при сохранении валидных).
  - Сигнал «Битый роут» (`code: 404, force_404: true`) при запросе параметров с неизвестными значениями, позволяющий клиентским сайтам мгновенно отдавать 404 без лишних тяжелых запросов.

## [2026-08-03]
