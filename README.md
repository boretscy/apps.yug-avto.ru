# apps.yug-avto.ru

Боевой серверный монолит + Go-микросервис для автоматизации автохолдинга (дилерская сеть).

## Стек

- **PHP 8.x** — серверный монолит (core, API, cron-задачи, views)
- **Go** — отдельный микросервис (go/) для высоконагруженных/фоновых задач
- **PWA** — прогрессивное веб-приложение для клиентов
- **CIS-интеграция** — парсинг и нормализация справочника CIS (модели, бренды, комплектации)
- **Trassir** — интеграция видеонаблюдения

## Что делает

- Синхронизация и нормализация данных о ТС (мульти-бренд, мульти-модель)
- Автоматизация дилерских операций через API
- Фоновые cron-задачи и Go-сервисы
- Клиентский фронтенд на PWA

## Основные модули

| Модуль | Назначение |
|--------|-----------|
| `API/` | REST API |
| `core/` | Ядро / бизнес-логика |
| `_cron/` | Планировщик фоновых задач |
| `go/` | Go-микросервисы |
| `pwa/` | Прогрессивное веб-приложение |
| `trassir/` | Интеграция видеонаблюдения |
| `views/` | Серверные шаблоны |

## Последние изменения

- Нормализация бренда Nordcross (Lynk & Co)
- Парсинг мульти-бренд / мульти-модель фильтров
- Синхронизация проданных авто и пулов настроек
